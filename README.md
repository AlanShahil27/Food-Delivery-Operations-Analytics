Food Delivery Operations & Delivery Performance Analytics

Project Overview

This project uses Power BI, Excel, and SQL to analyze food delivery operations and understand order trends, revenue, delivery delays, cancellations, and customer satisfaction.

Tools Used

	* Power BI
	* SQL
	* Microsoft Excel
	* DAX
	* Data Cleaning and Visualization

Dashboard Pages

	1. Executive Overview
	2. Customer & Order Analysis
	3. Delivery Performance
	4. Restaurant & Revenue Analysis
	5. Cancellation & Satisfaction Analysis
	6. Business Insights & Actions

Key Objectives

	* Identify cities with the highest order volume and revenue.
	* Understand factors associated with late deliveries.
	* Analyze order cancellations and customer ratings.
	* Turn findings into practical business recommendations.

Project Files

	* Power BI dashboard
	* Cleaned dataset
	* SQL analysis script
	* Excel analysis file

Outcome

	An interactive dashboard that helps users explore food delivery performance and identify areas for operational improvement.
